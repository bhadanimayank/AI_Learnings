# AI Engineering Journey

Learning reference for moving from Lead Full Stack Engineer to Applied AI Engineer.
Each lesson folder has a `README.md` (concepts, expected output, experiments, my notes)
and heavily commented, runnable code.

## Setup

```bash
# Install uv: https://docs.astral.sh/uv/
uv sync                     # creates .venv from pyproject.toml + uv.lock
cp .env.example .env        # add API keys only when a lesson needs them
uv run <path/to/script.py>  # run any lesson script from the repo root
```
